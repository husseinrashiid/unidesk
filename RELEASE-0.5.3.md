UniDesk 0.5.3

- Removed Study navigation, course Study sessions, the top-bar timer, quick-add study actions, study settings, study logging and exam plan generation. Existing stored records remain intact.
- Removed the course Resources tab. Existing files remain accessible in Materials. Ask course remains available as its own section.
- Materials now lists each document once when no search is entered. Read document opens its complete extracted text with page references and readable spacing. Search passage overlap is removed within each source location; full text is no longer cut into 350-character previews when browsing.
- Open original file remains available for the exact PDF layout and tables.

Validation: 68 automated tests, TypeScript build, and a browser workflow verifying removed controls, course navigation, email matching and reading the end of a long document without duplicated passages.

Update: close UniDesk and run D:\App\UniDesk-Setup.exe. If the installer asks, select Do not uninstall. Course data and files are preserved.
